# Respberry Windows Runner Releases

Öffentliches Release-Repository für den Windows Runner.

Enthält künftig ausschließlich veröffentlichte, geprüfte Update-Artefakte und das autoritative `latest.json`.

`latest.json` wird erst mit dem ersten tatsächlich gebauten und geprüften Windows-Release erzeugt. Ein Platzhalter wird bewusst nicht als produktives Manifest veröffentlicht.
